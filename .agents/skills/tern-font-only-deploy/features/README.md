# Tern 字体部署功能地图

从 [SKILL.md](../SKILL.md) 选择发布验证或正式升级入口。脚本覆盖地图中所有适用分支；前置条件缺失或身份不符时记录失败，不跳过检查。

| 功能 | 用户路径 | 主要证据 |
|---|---|---|
| [官方资源与字体判定](official-inputs.md) | 核对安装包、原版资源和匹配的字体检测 | 包成员、文件身份、检测分类 |
| [字体登记补丁](font-registration.md) | 为已审核的原版资源构建登记补丁 | 构建清单、hash、错误输入拒绝 |
| [站点资源装配](site-assets.md) | 按字体判定装配候选站点 | 站点清单、实际文件 hash |
| [服务与认证](service-auth.md) | 在独立服务上检查资源和 token 认证 | 进程身份、六项服务检查 |
| [升级与保留](upgrade-retention.md) | 经授权热切换正式服务并检查现有状态 | 升级前后窗格、程序和认证 |
