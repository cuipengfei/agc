## Selected source content

Mutation testing is a technique for evaluating the quality of a test suite. It inserts deliberate bugs into source code and checks whether the tests fail. A mutation that is not detected by the tests indicates a validation gap.

The technique is recommended when a team needs evidence that tests detect defects rather than only execute code.
