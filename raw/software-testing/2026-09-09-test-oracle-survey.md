# The Oracle Problem in Software Testing: A Survey

> Source: https://eecs481.org/readings/testoracles.pdf
> Collected: 2026-09-09
> Published: 2015

## Selected source content

A test oracle is a mechanism for checking the correctness of test results.

The oracle problem concerns determining whether the result of a test execution is correct. An oracle can be based on a specification, a reference implementation, a relation between executions, or another rule for deciding whether observed behavior is acceptable.
