# Efficient Mutation Testing by Checking Invariant Violations

> Source: https://www.st.cs.uni-saarland.de/publications/files/schuler-issta-2009.pdf
> Collected: 2026-09-09
> Published: 2009

## Selected source content

Mutation testing is a fault-based testing technique. It creates mutants by applying mutation operators to a program and evaluates a test suite by checking which mutants are detected.

Dynamic invariant detection can be used to identify program properties that hold during executions. The study investigates invariant violations as evidence that a mutation changes program behavior.

The source discusses equivalent mutants and the cost of executing many mutants. It uses invariant violations to focus mutation analysis on changes that affect observed program properties.
