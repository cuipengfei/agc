# 免费强模型 API 候选公开资料摘录

> Collected: 2026-09-02

以下是本轮检索保留的公开页面摘录。它们只证明页面声称的规则，不证明账号注册后当前一定可用；未登录、未创建 API key、未进行付费操作。

## AIHubMix

来源：
- https://docs.aihubmix.com/cn/blogs/free-ai-models
- https://aihubmix.com/model/gpt-5.5-free

页面声称：“提供 27+ 个真正免费的 LLM 与图像生成模型”，包括 “GPT-5.5、GPT-Image-2、Gemini 3”，并称“无需信用卡，无试用到期”。

`gpt-5.5-free` 模型页给出的限制是：每个账号“5 requests per minute, 500 requests per day, and 1 million tokens per day”。

同一组页面还出现两种新用户描述：一处称免费模型长期可用；另一处称“注册后，GPT-5.5、GPT-Image-2 等免费模型各赠送 10 次免费调用。充值可解锁更多额度”。

## 速语 API

来源：https://free.suyu.io/

页面声称使用 GitHub 账号登录即可获得免费 API key，无需付费；支持“GPT-5.5、Claude Sonnet、DeepSeek V4、Gemini 3.5”，并称“每天都有 GPT-5.5、Claude、DeepSeek、Gemini 的免费配额”。

页面展示的模型与额度文字包括：`gpt-5.5`，`claude-sonnet-4-6`，`gemini-3.5-flash`；搜索页面摘录还显示 GPT 系列 50 次/天、Claude 系列 30 次/天、Gemini 系列 100 次/天。额度是否对所有账号和地区实际生效，未登录验证。

## AnyRouter

来源：https://docs.anyrouter.top/

页面声称：“注册即送 $50 免费额度”，并列出“无需信用卡、无需付费”。页面说明服务可用于 Claude Code，并可获取 API 令牌。

公开资料还提到邀请奖励和每日签到，但本轮没有得到 AnyRouter 官方页面对每日签到金额、当前模型列表和持续可用性的完整确认。

## Eachof

来源：https://eachof.com/

页面展示 GPT-5.5、Claude 4 和 Gemini，并声称“每天签到可领取免费额度”，另有“模型限免与 Token 空投”。页面没有给出本轮可确认的固定签到金额或具体模型配额。

## HCNSEC 公益大模型网关

来源：https://vibex.iflow.cn/t/topic/6526

社区帖子声称该公益网关提供“免费 GPT、Claude、Gemini 接口”，支持注册赠送额度和“每日签到送额度”，并显示“注册送 29200 额度”。这是社区帖子，不是本轮核验到的服务方官方文档。

## QuickRouter.AI

来源：https://quickrouter.ai/

页面声称“注册免费送 $0.2 体验额度”，并列出“无需绑定信用卡”。页面说明可直接测试 Claude、OpenAI 和 Gemini；FAQ 举例使用 `claude-sonnet-4-6` 或 `gpt-5.4-mini` 测试。该额度是注册试用，不是每日签到额度。

## ChatAnywhere

来源：https://github.com/chatanywhere/GPT_API_free

公开仓库 README 声称免费版每天 `10000` 点额度，并列出 GPT-5 系列“一天 5 次”。同时 README 明确警告：“免费API gpt-5系列模型的推理能力较弱，若需要更强的推理能力，可以购买付费API”。免费 key 仅限个人非商业用途、教育和非营利性科研工作。

## FreeTokenRouter

来源：https://freetokenrouter.cn/

搜索页面摘录声称“现在注册，立即获得 1 million 免费 Token”，并写有“无需信用卡，无需付费，注册即可开始使用国内最强大模型”。本轮没有核验到强模型的准确模型 ID、每日重置规则或服务稳定性。

## Kilo Gateway

来源：https://kilo.org.cn/gateway

页面展示 Claude Opus 4.8、Claude Sonnet 4.6、GPT-5.5 和 Gemini 3 Pro 等模型，同时列出 Free 模式“$0/永久”，但免费模式的说明只是“访问默认免费模型”，没有确认上述旗舰模型属于免费层。

## APIDock

来源：https://apidock.ai/

页面声称“注册赠送 $1 额度”，可尝试 Claude、GPT 和 Gemini 最新模型；计费方式为按实际 Token 用量扣费。本轮没有发现每日签到或长期免费配额的公开说明。
