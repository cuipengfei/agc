> Collected: 2026-09-04
> Published: 持续更新（实时跟踪提供商状态）

## 站点概述

LMSpeed 是一个专注于 LLM API 的定价比较与速度基准测试平台，同时维护一个免费 LLM API 模型目录。

- 跟踪模型数：2824 个
- 覆盖提供商：158 个
- 免费模型分类：提供 `/free` 目录，可按模型筛选免费提供商
- 共享 API key：社区提交的 OpenAI-compatible key，需消耗积分解锁
- 公益提供商分类：`/provider/category/free` 专门收录公益站

## 与 baipiao.org 的差异

- **LMSpeed**：侧重基准测试和价格透明，提供实时速度/延迟数据；免费 key 需积分解锁；提供商需主动提交。
- **baipiao.org**：侧重社区投票评价，无速度数据；直接展示提供商链接；用户投票驱动排序。

## 证据边界

- 速度和基准数据来自 LMSpeed 的实测，但免费层的可用性可能随提供商策略变化。
- 共享 API key 为社区提交，LMSpeed 不担保 key 的持久可用性或安全性。
- 未登录验证积分系统和 key 解锁流程。
