# GitHub Copilot 模型托管说明（Gemini 在 GCP 托管）

> Source: https://docs.github.com/en/copilot/reference/ai-models/model-hosting
> Collected: 2026-10-19
> Published: Unknown

以下为页面关键原文摘录（英文原样保留，非全文）：

> GitHub Copilot uses Gemini models hosted on Google Cloud Platform (GCP).

页面的模型清单中列有 Gemini 3.8 Flash（经 Copilot 提供），并说明 Copilot 在使用 Gemini 模型时采用 Google Durable Caching。

页面同时说明，Copilot 请求会经过 Copilot 的内容过滤系统（content moderation）。

采集备注：以上摘录用于支撑两点事实——(1) Copilot 的 Gemini 运行在 GCP；(2) Copilot 使用 Google Durable Caching。页面未披露 Copilot 到 Google 的具体路由、项目或区域。
