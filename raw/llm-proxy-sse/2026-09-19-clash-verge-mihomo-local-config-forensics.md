## 8. 对 LLM SSE 流式调用的直接影响（事实层）

- 出站 TCP keepalive 15s idle / 15s interval 已启用 → 空闲 SSE 连接由 mihomo 自己保活，但**上游节点/中转的超时与此无关**。
- 没有 url-test 组 → 节点不健康时只能靠 fallback(7200s 周期, lazy) 或手动切换；SSE 长连接挂上慢节点不会被自动迁移。
- auto_close_connection=false + TUN strict-route → 已建立的 SSE 流不会被策略切换主动重置。
- fake-ip + sniffer(无 force-domain) → LLM 域名按规则直连分流，sniff TLS SNI 正常解析，不影响 API 域名路由。
- dial-timeout 未设置（默认 5s? 以 mihomo 源码默认值为准，本机未覆盖）。
