## Sim
- https://github.com/simstudioai/sim - 29,491 stars, Apache-2.0, 最新 v0.8.17（2026-08-29）
- 可视化工作流画布: agent 通过 Mothership 创建或修改节点, 边, agents/functions/conditions/loops
- 在同一画布上执行和监控
- 人: 拖放, 配置, 审批
- 团队实时协作, 带光标和 undo
- Agent-人共享模式: agent 修改工作流图, 人审批/配置, 双方看到同一执行状态
- 非手绘自由画布; 节点 = 执行步骤, 边 = 数据流
- 适用场景: API 编排, 数据管道, 多 agent 工作流, 业务流程自动化
