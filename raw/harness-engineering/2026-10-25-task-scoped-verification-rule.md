# 按任务类型与授权范围选择验证方式

> Source: 用户批准的验证条款替换文本；本机 `~/.claude/CLAUDE.md`「工作流程」与「别让 skill 改掉当前任务」
> Collected: 2026-10-25
> Published: Unknown

## 用户级验证条款原文

在 `~/.claude/CLAUDE.md` 的 `### 工作流程` 中，以以下条款替换现有的验证要求：

```markdown
- 对于已获授权的实现或修改，必须完成与改动相匹配的验证并处理发现的问题。代码功能应运行相关测试并验证实际行为；文档、规则和 skill 文案应检查内容、格式、引用与示例一致性。对 skill 文案进行真实模型调用、付费 API 实验、压力测试或对照抽样，须经用户明确授权。验证结果按实际执行的项目报告，不把未执行的检查写成通过。
```

## 复刻范围

- 仅替换「工作流程」中的验证条款，其余工作流程条目保持不变。
- 「别让 skill 改掉当前任务」保持原文：

```markdown
#### 别让 skill 改掉当前任务

用户问什么、要什么格式，就按用户的要求交。借用 skill 里的表达原则时，保留当前回答需要的解释、条件和证据。

skill 里自带的只交改写稿、逐段确认、写文件等流程，只有用户真让你做这些事时才走。读了 skill 不代表用户多授权了别的动作。
```

## 本地核对

- 验证条款在用户级源文件中只出现一次，并与 wiki 中的复刻文本逐字一致。
- `~/.claude/CLAUDE.md` 保持用户级共享规则的唯一来源；`~/.codex/AGENTS.md` 与 `~/.omp/agent/AGENTS.md` 仍指向它。
- 本条款的文案核对使用内容、格式、引用和一致性检查，不发起额外模型实验。
