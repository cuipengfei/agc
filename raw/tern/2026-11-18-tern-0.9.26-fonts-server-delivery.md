## 与 0.9.23 的跨版本对照

用 0.9.23 binary 在 `127.0.0.1:18788` 起临时服务（未触碰 0.9.26 的 systemd 单元），发送同样的两组请求：

| 请求 | 0.9.23 临时服务响应 | 0.9.26 运行中服务响应 |
|---|---|---|
| `GET /fonts?chars=4e2d` | `200`、`application/json`、`Content-Length: 63`、`Cache-Control: no-store`；`{"fonts":[{"id":"b76b0433203017ca80401b2ee0dd6935","index":2}]}` | 相同 |
| `GET /fonts?chars=4e2d&families=Maple%20Mono%20NF%20CN` | `{"fonts":[{"id":"b3f8f26efab7c88f4f72cff0fe02a3c8","index":0}]}` | 相同 |
| `GET /fonts/b76b0433203017ca80401b2ee0dd6935` | `200`、`font/sfnt`、`Cache-Control: private, max-age=31536000, immutable`；`19484784` 字节 | 相同 |
| `GET /fonts/b3f8f26efab7c88f4f72cff0fe02a3c8` | 同上；`20561696` 字节 | 相同 |

0.9.26 侧对应响应：`GET /fonts?chars=4e2d` 与 `families=Maple%20Mono%20NF%20CN` 分别返回上述两个 JSON 与字体 ID；`GET /fonts/b76b0433203017ca80401b2ee0dd6935` 返回 `200`、`font/sfnt`、`Cache-Control: private, max-age=31536000, immutable`、`19484784` 字节（对应 WSL `/usr/share/fonts/opentype/noto/NotoSansCJK-Regular.ttc`）；`GET /fonts/b3f8f26efab7c88f4f72cff0fe02a3c8` 返回同头与 `20561696` 字节（对应 WSL `~/.local/share/fonts/maple-win/.../MapleMono-NF-CN-Regular.ttf`）。

字体 ID、字节数与响应头在 0.9.23 临时服务与 0.9.26 运行中服务上均相同：`/fonts` 通道行为跨版本一致，服务端按 `families=` 参数区分投递的字体文件，字体来源是运行 `tern web serve` 的 WSL 本机字体目录。

`pkg/stencil_tern_web.js`（`138543` 字节）中 `writeTexture` 出现 2 次；页面 glue 通过 `__wbg_*` 绑定与 WASM 交互。0.9.26 安装包内只有 `tern/tern` 一个可执行文件，WASM 由 `build.stencil.so` CDN 提供，本地无独立 WASM 文件可比对；`/fonts` 通道结论以对运行中服务的 HTTP 实测为准。

## 渲染链路（源自 0.9.23 静态证据，0.9.26 服务端行为一致）

`pkg/client.js`（0.9.23 官方 glue，`84621` 字节）中 `CanvasRenderingContext2D.fillText` 与 `measureText` 出现次数均为 0。WASM 内嵌 `harfrust-0.12.0`（排版）与 `skrifa-0.44.0`（光栅化），经 `__wbg_writeTexture_30e592e8c061c3d9`（`queue.writeTexture`）上传 WebGPU 纹理图集（`crates/gfx/src/atlas.rs`）。WASM 模块 `crates/tern/src/web/fonts.rs`（日志名 `stencil_tern::web::fonts`、函数 `web_font_land`）的请求字面量包含 `./fonts?chars=`、`&families=`、`./fonts/`、`the server named no fonts`、`a font of the host did not load`、`a font of the host from the cache`、`the cache did not keep a font` 与缓存名 `tern-fonts`；glue 绑定 `Window.caches`（`__wbg_caches_0681678104a6b0bf`）、`CacheStorage.open`（`__wbg_open_c35e93b027257492`）、`Cache.match`（`__wbg_match_c9682c7274131c0d`）、`Cache.put`（`__wbg_put_bbca42771defa466`），WASM 拿到字体字节后调用 `crates/text/src/fonts.rs` 的 `font_register` 注册进内存字体库。该组字面量在 0.9.18、0.9.21 与 0.9.23 的 `original.wasm` 中均存在。

## 对补丁流程的影响

内嵌字体装配（`prepare` → `font_manifest.py` → `assets --official`）在服务端宿主机已安装目标字体且浏览器配置了 `font_family` 的前提下不再必要：默认中文由 WSL 本机 `NotoSansCJK-Regular.ttc` 投递，配置 `Maple Mono NF CN` 后由 WSL 本机 `MapleMono-NF-CN-Regular.ttf` 投递。此前提交 `5de48ac` 中「Chrome 内核在 canvas 上补绘中文」的解释有误，本轮以 `/fonts` 实测为准更正。
