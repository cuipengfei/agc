> Source: 本机 2026-10-29 实测。官方包 `Tern-0.9.7-linux-x86_64.tar.gz` 取自 Windows 下载目录，解压到 `/tmp/tern-0.9.7-check-nCMXWP`；原版资源由 `bun cli.mjs prepare` 取得并经 SHA-384 校验；字体由 `font_manifest.py` 生成，网页由 `bun cli.mjs assets --official` 装配；正式升级用 `bun cli.mjs upgrade`，报告写入 `~/.local/share/tern-web-0.9.7/verification/`。
> Collected: 2026-10-29

## 静态分析与时间分支

```text
$ bun cli.mjs analyze --wasm pkg/original.wasm --fonts fonts.json --out plan.json
{"schemaVersion":1,"inputSha256":"fafe58c52cc837f81342139da7e147ec2bce25d750b65cdbe533cfd2fc3e65f1","fonts":2,"panics":31,"decision":"manual_review_required"}
```

`panics` 字段是 `panicFunctions` 的总体数量，不等于时间分支数量。按消息 `time not implemented on this platform` 筛选后：

| 版本 | panicFunctions 总数 | 时间函数与调用数 | 时间调用合计 |
|---|---:|---|---:|
| 0.9.7 | 31 | `30815`（18 处）、`30816`（3 处） | 21 |
| 0.9.6 | 32 | `30720`（22 处）、`30721`（3 处） | 25 |

本版本没有应用时间补丁。

    --fonts ~/.local/share/tern-fonts-0.9.7 --out ~/.local/share/tern-web-0.9.7

    --candidate-binary ~/.local/share/tern-native-0.9.7/tern \

    --assets ~/.local/share/tern-web-0.9.7 \
    --state-dir ~/.local/share/tern-native-0.9.7/runtime-state \

## 证据边界

- 只做了一个 Windows 11 主机与一个 Windows Chrome 的页面验收；其他浏览器、操作系统和物理机器未验证。
- 验收覆盖挂载、字体注入、WebGPU adapter、WebSocket frame 数与页面错误；不检查字形外观、字符宽度或完整 Markdown 渲染语义。
- native desktop UI 未运行。
- 用户对该版本的日常操作反馈尚未记录；0.9.6 时期用户反馈为打开含中文的 Markdown 正常。
