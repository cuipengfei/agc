## 原版时间 panic 复现

panic 函数 `30563`（21 个直接调用）与 `30564`（5 个直接调用），消息 `time not implemented on this platform`。实际调用两个函数均抛出 `unreachable`。

## 补丁映射

26 处调用点：日历时间复用既有函数 `25011`；新增单调时钟函数 `32181`（`performance.now`）与 `32182`（elapsed）；跨秒相减复用既有饱和函数 `22956`；externref 由既有函数 `24515` 释放。字体初始化改为读取槽位 `9031308`/`9031312`、`9031332`/`9031336` 的 descriptor。没有新增 import，原函数编号保持。

补丁 WASM SHA-256 `bcb60f010b308af22da907513c992b073a51fd427b8702da3b9a6425ec8d1492`，测试模块 SHA-256 `87136dec3aa01b8a844b11ae504928e68210825062e022e5a3a6067edf281055`。

## 验收结果

- 结构：imports、exports、function signatures、memory limits、initial memory 全部 passed。
- 时间行为：instrumented module provenance、calendar epoch and bounds、instant fractional seconds and bounds、elapsed borrow and saturation、actual consumer、externref reuse 10000 calls 全部 passed。
- Headless 浏览器：模块初始化与完整字体注入通过，收到 33 个 WebSocket frame，pageerror 0；视觉效果由用户检查。
- 正式服务：HTTP 200、补丁 WASM 指纹、既有 token WebSocket 认证通过；`web serve` 监听 `127.0.0.1:8378`。

## 运行进程取证

首次替换只更新 CLI 与 Web，旧 daemon 进程继续驻留。`/proc/29986/exe` 显示旧文件已删除且 inode 与安装文件不同，证明替换路径不会改变已运行进程。

统一重启后：daemon、Web 服务与安装文件的 inode 均为 `238854`；进程树为 `daemon.py` → `tern daemon`、`serve.py` → `tern web serve`，两个 Python 进程各负责一个 Tern 子进程的生命周期管理。查询返回四个既有 pane ID：`326417514501`、`326417514503`、`347892350977`、`382252089349`。
