## 无补丁装配边界

`prepare` 输出目录只有 `official.html`、`pkg/client.js`、`pkg/original.wasm`、`initial.bin`、`inputs.json`，入口文件名不是 `index.html`。把这个目录或其副本指给 `tern web serve --assets` 时，根页面缺入口或脚本。

因此本轮 Web 服务不传 `--assets`，由 binary 提供内嵌官方页面：

| 请求路径 | HTTP |
|---|---|
| `/` | 200，页面 preload 指向 `https://build.stencil.so/web/tern/0.9.23/stencil_tern_web_bg.wasm` |
| `/pkg/stencil_tern_web.js` | 200 |
| `/pkg/client.wasm` | 404 |
| `/pkg/client.js` | 404 |

`pkg/client.wasm` 与 `pkg/client.js` 是仅字体装配产物的路径，官方内嵌站不提供，这是既有事实。

`verify-service` 固定抓取 `pkg/client.wasm`、`pkg/client.js` 与本地 assets 比对（`tools/tern-maintain/lifecycle.mjs:316-328`），对内嵌官方资源不适用。本轮验收改用 `inspect-runtime` 等价字段、根页面 HTTP 状态、页面内 WASM 地址、pane 列表。

响应头包含 `Cache-Control: no-cache`。

## systemd 用户服务

两个单元文件放在 `~/.config/systemd/user/`，权限 `664`：

`tern-daemon.service`：

```
[Unit]
Description=Tern daemon
StartLimitIntervalSec=0

[Service]
Type=simple
Environment=TERN_DAEMON_SOCKET=/run/user/1000/tern/daemon.sock
ExecStart=/home/cpf/.local/bin/tern daemon --socket /run/user/1000/tern/daemon.sock
Restart=always
RestartSec=3
StandardOutput=null
StandardError=null

[Install]
WantedBy=default.target
```

`tern-web.service` 的差别在 `Wants=`／`After=tern-daemon.service` 与：

```
ExecStart=/home/cpf/.local/bin/tern web serve --listen 127.0.0.1:8378 --token /home/cpf/.config/tern/web-token
```

`StandardOutput=null` 与 `StandardError=null` 同时避免 `web serve` 启动时把带 token 的 URL 写进日志。两个单元 `Restart=always`、`RestartSec=3`，`systemctl --user is-enabled` 返回 `enabled`。

进程形态：daemon pid `2317693`、web pid `2317236`，`PPID` 均为 `273`，`SID` 等于各自 pid，控制组分别为 `user.slice/user-1000.slice/user@1000.service/app.slice/tern-daemon.service` 与 `.../tern-web.service`。

## 重启自愈实测

对 web 单元执行 `systemctl --user kill --kill-whom=main --signal=KILL tern-web.service` 后，主进程换号，`ActiveState` 仍为 `active`，`NRestarts` 从 0 变 1。`journalctl --user -u tern-web.service` 记录两条：`Main process exited, code=killed, status=9/KILL` 与 `Scheduled restart job, restart counter is at 1.`。

daemon 单元未做终止测试，以保留现有 pane。

## 与 0.9.21 的差异

0.9.21 部署目录 `~/.local/share/tern-web-0.9.21` 记录 `mode` 为 `font-only`，含 `pkg/client.wasm`、`pkg/client.js` 与两份 Maple 字体。0.9.23 本轮没有任何装配产物，服务直接使用 binary 内嵌页面，因此不存在 `deploy-manifest.json`，也不存在字体或时间改动。
