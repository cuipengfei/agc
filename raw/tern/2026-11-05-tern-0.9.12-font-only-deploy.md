## 证据边界

WSL 本机 headless Chromium 在 loopback 安全上下文里 `navigator.gpu` 存在，但 `requestAdapter()` 在 baseline、`--enable-unsafe-webgpu --ignore-gpu-blocklist`、再加 `--use-angle=swiftshader` 三种组合下均返回 null。真实浏览器 mount 与 WebSocket frame 未在本轮采集，记 `not_run`；完整 GPU 挂载证据按仓库既有边界需另用 Windows Chrome 路径验证。这是 WSL 本机 headless 环境的观测。

0.9.11 未部署，用户直接提供 0.9.12；中间版本没有任何实测数据。本轮未运行 native desktop UI，未执行 Markdown 冻结复现；完整字形、字符宽度和日常 Markdown 操作由用户继续测试。
