## 官网：产品与平台

Source: https://alma.now/zh/

> Alma 本身就是一个完整的 Agent harness：所有 AI 模型、Skills 与 MCP、它自己操作的浏览器、Artifacts，以及真正属于你的记忆。它同时也是 Mac、Windows、Linux、iPhone 和 Android 上的 herdr 图形客户端：每个 Claude Code、Codex 和 pi Agent 都是一段干净的对话，等你的排最前。

> 桌面端支持 macOS（Apple Silicon 与 Intel）、Windows 和 Linux，herdr 能跑的地方都行；iPhone 通过 TestFlight、Android 通过 APK 安装，与电脑上的 Alma 配对使用。远程屏幕（在手机上查看并操控桌面）需要 Mac。

> 对话保存在你自己电脑上的数据库里，API Key 直连各家服务商。

下载区列出 Windows 的 `.exe`，Linux 的 AppImage、`.deb` 与 `.rpm`，以及 macOS 下载项。

## 快速开始

Source: https://alma.now/docs/zh/guide/quick-start

> 首次启动 Alma 时，你需要配置至少一个 AI 服务商。

> 1. 打开 **设置**（`Cmd/Ctrl + ,`）
> 2. 进入 **服务商** 选项卡
> 3. 选择一个服务商（如 OpenAI）
> 4. 输入你的 API 密钥
> 5. 点击 **保存**

> 将聊天与项目目录关联：
> 1. 点击侧边栏中的工作区图标
> 2. 选择一个项目文件夹
> 3. AI 现在可以访问你的文件了

## 工具与权限

Source: https://alma.now/docs/zh/features/tools

> Alma 包含 20+ 内置工具，让 AI 能够执行超越文本生成的操作。

> 安全的只读操作自动运行：
> - 读取文件
> - 搜索内容
> - 网页获取

> 可能有影响的操作会请求批准：
> - 写入文件
> - 运行 Shell 命令
> - 删除内容

文档列出文件操作、Shell、网页搜索和内置浏览器工具，以及来自 MCP 服务器的附加工具。

## 记忆

Source: https://alma.now/docs/zh/features/memory

> Alma 可以记住跨对话的重要信息。

> 1. **提取**：在对话过程中，Alma 识别重要信息
> 2. **存储**：记忆以语义嵌入方式存储
> 3. **检索**：当相关时，记忆会自动出现在上下文中

> 在记忆浏览器中：
> - 搜索特定记忆
> - 编辑内容
> - 删除不需要的记忆

## Artifacts

Source: https://alma.now/docs/zh/features/artifacts

> 当 AI 生成特定类型的内容时，Alma 可以将其渲染为可视化预览：
> - HTML 页面
> - React 应用
> - SVG 图形
> - Mermaid 图表
> - Markdown 文档

> 点击 Artifact 卡片展开预览面板。
