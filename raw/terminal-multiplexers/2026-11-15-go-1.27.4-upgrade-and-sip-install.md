# Go 1.27.4 升级与 sip v0.10.0 安装

## Go 不归 apt 管

`dpkg -S /usr/local/go/bin/go` 输出：

```
dpkg-query: no path found matching pattern /usr/local/go/bin/go
```

Go 安装在 `/usr/local/go/bin/go`，由官方 tarball 手动安装，不归 `apt` / `dpkg` 管理。`apt upgrade` 不会更新它。

## 升级到 go1.27.4

下载地址：`https://go.dev/dl/go1.27.4.linux-amd64.tar.gz`

官方 SHA-256 校验命令（校验通过）：

```bash
curl -fsSL 'https://go.dev/dl/go1.27.4.linux-amd64.tar.gz.sha256' | sha256sum -c -
```

安装步骤（替换旧版并清理旧目录）：

```bash
sudo rm -rf /usr/local/go
sudo tar -C /usr/local -xzf /tmp/go1.27.4.linux-amd64.tar.gz
```

`go version` 输出：

```
go version go1.27.4 linux/amd64
```

## GOTOOLCHAIN 后续更新机制

Go 1.21 引入 `GOTOOLCHAIN` 环境变量，允许在构建时自动下载并使用更新的 Go 版本。

设置方式（写入 `go env` 持久生效）：

```bash
go env -w GOTOOLCHAIN=go1.27.4+auto
```

恢复由 `/usr/local/go` 决定默认版本：

```bash
go env -u GOTOOLCHAIN
```

查询当前生效值：

```bash
go env GOTOOLCHAIN
```

## 安装 sip v0.10.0

安装命令：

```bash
go install github.com/Gaurav-Gosain/sip/cmd/sip@latest
```

安装路径：`/home/cpf/go/bin/sip`

`go version -m /home/cpf/go/bin/sip` 关键输出行：

```
path    github.com/Gaurav-Gosain/sip/cmd/sip
mod     github.com/Gaurav-Gosain/sip v0.10.0
build   -compiler gc
build   go1.27.4
```

确认 sip 使用 go1.27.4 编译。
