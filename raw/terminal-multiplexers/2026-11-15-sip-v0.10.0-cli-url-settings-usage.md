## 设置面板（浏览器右上角齿轮）

设置面板 HTML 控件与默认值（来源：sip v0.10.0 内置 `index.html` 与 `terminal.js`）：

| 控件 | HTML 元素 ID | 默认值 | 可选值 |
|---|---|---|---|
| Transport | `transport-select` | `auto` | `auto` / `webtransport` / `websocket` |
| Renderer | `renderer-select` | `auto` | `auto` / `webgl` / `canvas` / `dom` / `vtgl` / `engine` |
| Font Size | `font-size` | `14` | 滑杆 10–28（px） |
| Copy on select | `copy-on-select` | 未勾选 | 复选框 |
| Blink cursor | `cursor-blink` | 未勾选 | 复选框 |
| Browser right-click menu | `browser-context-menu` | 未勾选 | 复选框（按住 Shift 右键始终可呼出） |
| Capture reserved keys | `capture-reserved-keys` | 已勾选 | 复选框（仅全屏模式生效） |

保存键名：`localStorage["sip-web-settings"]`（JSON 字符串）

Apply & Reconnect 按钮行为：
- 若改了 Renderer：浏览器整页刷新，旧 shell 结束，新开 shell。
- 若只改 Transport / Font Size / 复选框：不整页刷新，但会重连；重连断开旧传输连接并新建会话，旧 shell 被结束（Kill），随后启动新 shell。使用 herdr 或 tmux 时可重新连接原会话。

## URL 参数

| 参数 | 可选值 | 行为 |
|---|---|---|
| `?renderer=` | `webgl` / `canvas` / `dom` / `vtgl` / `engine` / `auto` | 设置当前标签页的首选渲染器，优先级最高；初始化失败时仍可能回退 |
| `?mobile=` | `1` / `0` | `1` 强制开启触屏按键栏；`0` 强制关闭 |
| `?vtglShaper=` | `pfb` / `none` | 仅 `renderer=vtgl` 时生效 |
| `?vtglBackend=` | `canvas2d` | 仅 `renderer=vtgl` 时生效 |

## 三处入口优先级（渲染器为例）

1. URL `?renderer=`（最高，仅当前标签页）
2. 浏览器 `localStorage["sip-web-settings"].renderer`（当前浏览器长期保存）
3. CLI `--renderer`（所有新客户端的初始默认值）

## 字体机制

- `--font-family "Maple Mono NF CN, monospace"`：把字体名写入网页配置；浏览器还会接收 sip 注册的网页字体。sip v0.10.0 在本机 Chrome 实测中选中了注册为 Maple 名称的内置 JetBrains，具体证据见 [字体匹配与 Console 验证](2026-11-15-sip-maple-font-resolution-and-console.md)。
- `--font /path/to/font.ttf`：通过 `/static/fonts/custom*` 路由向浏览器提供指定字体文件。本机同时设置 Maple 字体文件与字体名称后，测试文字仍命中内置 JetBrains。
- 两者都不传：使用 sip 内置的 JetBrainsMono Nerd Font Mono（WOFF2）。

## OSC 52 剪贴板

- 写入（开启）：程序输出 `\e]52;c;<base64>\a` 时，浏览器直接把解码后文本写入系统剪贴板。
- 读取（忽略）：程序发送 `\e]52;c;?\a` 查询剪贴板内容时，浏览器忽略该请求，不回传任何内容。

## 图形协议

- Kitty graphics：客户端默认开启，浏览器内用 `createImageBitmap` 解码 PNG。
- Sixel：客户端默认开启，通过 xterm.js image addon 渲染。
- `--enable-kitty-transcoder`：不是 Kitty 总开关，只是服务端把 PNG 转 RGBA 的兜底转码器，正常浏览器不需要开。

## 环境变量

- `SIP_PASSWORD`：Basic Auth 密码，优先级 `--basic-pass-file` > `SIP_PASSWORD` > `--basic-pass`。sip 读取后从子进程环境移除。
- `SIP_DEBUG_INPUT`：非空时记录客户端原始输入字节。
